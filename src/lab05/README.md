# Лабораторная работа №5: JSON, CSV и XLSX

## Описание
В рамках работы реализованы функции для конвертации форматов данных:
- `src/lab05/json_csv.py` — конвертация JSON ↔ CSV.
- `src/lab05/csv_xlsx.py` — конвертация CSV → XLSX (с использованием `openpyxl`).

## Установка зависимостей
Для работы с Excel необходимо установить библиотеку `openpyxl`:
pip install -r requirements.txt

## Команды запуска
Тестирование производилось через вызовы внутри самих файлов (блок `if __name__ == "__main__":`).

### Задание А: JSON ↔ CSV
Запуск:
python src/lab05/json_csv.py

Результат: создаются файлы `data/out/people_from_json.csv`, `data/out/users_from_json.csv`, `data/out/people_from_csv.json` и `data/out/users_from_csv.json`.

### Задание B: CSV → XLSX
Запуск:
python src/lab05/csv_xlsx.py

Результат: создаются файлы `data/out/people.xlsx` и `data/out/cities.xlsx`. Внутри файлов лист называется "Sheet1", ширина колонок подстраивается под текст (минимум 8 символов).

## Описание форматов и допущения
1. **Порядок колонок при JSON → CSV:** Колонки формируются в том порядке, в котором ключи впервые встречаются в объектах входного JSON-массива.
2. **Отсутствующие поля:** Если в одном из объектов JSON отсутствует ключ, который есть в других, в CSV-файле на этом месте будет пустая строка (заполняется автоматически).
3. **Типы данных:** При конвертации CSV → JSON все значения сохраняются как строки.
4. **Обработка ошибок:**
   - Если файла не существует, выбрасывается `FileNotFoundError`.
   - Если JSON пустой, не является списком или содержит не-словари, выбрасывается `ValueError("Пустой JSON или неподдерживаемая структура")`.
   - Если CSV пустой или не имеет заголовка, выбрасывается `ValueError("CSV без заголовка или пустой")`.
   - Если передан неверный тип файла (например, JSON вместо CSV для Excel), выбрасывается `ValueError`.
